Untuk Utero Indonesia, kategori administrasi ERP sebaiknya mengikuti perjalanan pekerjaan: **calon klien → penawaran → order → pengerjaan → pengiriman → penagihan → pembayaran**. Pembelian, stok, dan partner produksi mendukung proses tersebut.

Dengan begitu, admin bisa menelusuri satu pekerjaan dari awal sampai selesai melalui **satu nomor proyek**.

**1. Administrasi pelanggan dan penjualan**

| Dokumen / fitur | Fungsi |
|---|---|
| **Database pelanggan** | Menyimpan identitas perusahaan, alamat, PIC, kontak, alamat penagihan, dan ketentuan pembayaran. |
| **Database prospek / CRM** | Mencatat calon klien, kebutuhan, sumber informasi, status komunikasi, serta jadwal follow-up. |
| **Form brief / permintaan pekerjaan** | Mencatat kebutuhan desain atau produksi: lingkup, ukuran, jumlah, bahan, lokasi, anggaran, dan tenggat. |
| **Surat penawaran / quotation** | Menawarkan lingkup, spesifikasi, harga, jadwal, masa berlaku, dan termin. |
| **RAB / kalkulasi harga internal** | Menghitung biaya bahan, tenaga, vendor, operasional proyek, dan margin yang ditargetkan. |
| **BOQ / rincian volume pekerjaan** | Merinci item, satuan, volume, spesifikasi, dan harga untuk pekerjaan yang membutuhkan perincian. |
| **Riwayat negosiasi dan revisi penawaran** | Menyimpan perubahan harga, lingkup, spesifikasi, serta persetujuannya. |
| **Dokumen registrasi vendor** | Mengelola berkas Utero untuk pendaftaran sebagai vendor calon klien. |
| **Kontrak / perjanjian kerja sama** | Mencatat kesepakatan proyek, retainer, atau kontrak vendor berkala. |

**2. Administrasi penerimaan order**

| Dokumen / fitur | Fungsi |
|---|---|
| **PO pelanggan** | Menyimpan pesanan resmi dari klien beserta nomor referensinya. |
| **Sales Order / Slip Order** | Mencatat order yang telah diterima dan disetujui untuk diproses internal. |
| **SPK pelanggan** | Menyimpan surat perintah kerja dari klien apabila digunakan sebagai dasar pekerjaan. |
| **Checklist kelengkapan order** | Memastikan brief, harga, spesifikasi, file, jadwal, dan persetujuan tersedia. |
| **Jadwal termin proyek** | Mencatat tahapan penagihan: uang muka, progres, pengiriman, atau pelunasan. |
| **Form perubahan pekerjaan / change order** | Mencatat tambahan, pengurangan, dan perubahan lingkup berikut dampak biaya serta waktunya. |

**Slip Order menjadi penghubung antara penjualan dan operasional.** Setelah order disetujui, Manajer Operasional menerbitkan penugasan sesuai jenis pekerjaan.

**3. Administrasi pekerjaan kreatif dan desain**

| Dokumen / fitur | Fungsi |
|---|---|
| **Creative brief** | Menjelaskan tujuan komunikasi, target audiens, pesan, arah visual, dan hasil yang dibutuhkan. |
| **Job Order / Surat Tugas Internal** | Menentukan pekerjaan, PIC, prioritas, tenggat, dan hasil yang harus diserahkan. |
| **Timeline pekerjaan** | Mengatur tahap konsep, pengerjaan, review, revisi, dan penyerahan. |
| **Form pengumpulan materi klien** | Memastikan logo, teks, foto, ukuran, dan materi lain sudah diterima. |
| **Log revisi** | Mencatat permintaan revisi, versi file, tanggal, dan status penyelesaiannya. |
| **Form persetujuan desain / artwork approval** | Menyimpan persetujuan klien atas desain sebelum finalisasi atau produksi. |
| **Daftar hasil kerja / deliverables** | Mencatat file, format, ukuran, jumlah versi, serta tautan penyerahan. |
| **Arsip aset dan hak penggunaan** | Mencatat sumber foto, font, musik, footage, dan ketentuan penggunaannya. |

Untuk jasa branding, hasil akhirnya bisa berupa strategi, logo, panduan identitas, kemasan, atau materi komunikasi. Setiap hasil perlu tercantum dalam daftar deliverables.

**4. Administrasi produksi**

| Dokumen / fitur | Fungsi |
|---|---|
| **SPK Produksi / Production Order** | Memberikan instruksi produksi berdasarkan order dan desain yang disetujui. |
| **Lembar spesifikasi produksi** | Menetapkan ukuran, bahan, ketebalan, warna, jumlah, finishing, dan metode pengerjaan. |
| **Daftar kebutuhan bahan / BOM** | Menghitung bahan dan komponen yang diperlukan untuk produksi. |
| **Form permintaan bahan** | Mengajukan pengambilan bahan dari gudang. |
| **Bukti pemakaian dan pengembalian bahan** | Mencatat bahan yang dipakai, tersisa, dan dikembalikan. |
| **Laporan progres produksi** | Mencatat tahap pengerjaan, jumlah selesai, hambatan, dan perkiraan penyelesaian. |
| **Form persetujuan sampel** | Menyimpan persetujuan contoh sebelum produksi massal apabila diperlukan. |
| **Checklist Quality Control / QC** | Memeriksa kesesuaian hasil terhadap spesifikasi. |
| **Form pengerjaan ulang / rework** | Mencatat kesalahan, penyebab, tindakan perbaikan, serta biayanya. |
| **Laporan hasil produksi** | Mencatat jumlah hasil baik, produk gagal, dan pekerjaan yang siap dikirim. |

**5. Administrasi pembelian dan partner**

| Dokumen / fitur | Fungsi |
|---|---|
| **Database supplier dan partner** | Menyimpan layanan, kontak, kemampuan, harga referensi, kapasitas, serta riwayat pekerjaan. |
| **Purchase Request / Permintaan Pembelian** | Mengajukan kebutuhan bahan, barang, atau jasa. |
| **RFQ / Permintaan Penawaran Vendor** | Meminta harga berdasarkan spesifikasi yang sama. |
| **Tabel perbandingan vendor** | Membandingkan harga, kualitas, waktu, ongkir, garansi, dan termin. |
| **Purchase Order / PO Pembelian** | Memesan barang atau jasa kepada supplier yang telah disetujui. |
| **SPK Partner / Subkontrak** | Menugaskan pekerjaan kepada partner dengan lingkup, standar, harga, dan tenggat yang jelas. |
| **Bukti penerimaan barang / jasa** | Memastikan pesanan telah diterima sesuai jumlah dan kualitas. |
| **Invoice / nota supplier** | Menyimpan tagihan dan bukti pembelian dari pemasok. |
| **Form retur / komplain supplier** | Mencatat barang atau hasil pekerjaan yang perlu diganti atau diperbaiki. |
| **Evaluasi partner** | Menilai ketepatan waktu, kualitas, komunikasi, dan penyelesaian keluhan. |

**PO pelanggan dan PO pembelian harus dibedakan:** yang pertama diterima dari klien, yang kedua diterbitkan Utero kepada pemasok.

**6. Administrasi gudang dan inventaris**

| Dokumen / fitur | Fungsi |
|---|---|
| **Master barang dan bahan** | Menyimpan kode, nama, satuan, spesifikasi, serta lokasi penyimpanan. |
| **Bukti barang masuk** | Mencatat penerimaan bahan, barang jadi, atau pengembalian barang. |
| **Bukti barang keluar** | Mencatat bahan untuk proyek, barang untuk pengiriman, atau pemakaian internal. |
| **Kartu stok** | Menampilkan saldo dan riwayat pergerakan setiap barang. |
| **Form stock opname** | Membandingkan jumlah fisik dengan catatan sistem. |
| **Form penyesuaian stok** | Mencatat selisih beserta alasan dan persetujuannya. |
| **Form peminjaman alat** | Mencatat alat yang dibawa tim atau partner dan jadwal pengembaliannya. |
| **Daftar aset dan perawatan** | Mengelola komputer, kamera, mesin, kendaraan, serta perlengkapan kerja. |

**7. Administrasi pengiriman dan pemasangan**

| Dokumen / fitur | Fungsi |
|---|---|
| **Packing list** | Merinci isi paket, jumlah, dan identitas barang. |
| **Surat Jalan** | Menjadi dokumen pengantar barang dari Utero ke penerima. |
| **Surat tugas pemasangan** | Menentukan tim, lokasi, waktu, lingkup, dan kebutuhan pemasangan. |
| **Form survei lokasi** | Mencatat ukuran lapangan, akses, kondisi struktur, listrik, dan kebutuhan teknis. |
| **Checklist pemasangan** | Memeriksa kesiapan, hasil, dan kondisi lokasi setelah pekerjaan. |
| **Bukti pengiriman / penerimaan** | Menyimpan nama penerima, tanggal, tanda tangan, dan dokumentasi. |
| **Berita Acara Serah Terima / BAST** | Mencatat penyerahan dan penerimaan pekerjaan oleh klien. |
| **Form komplain dan garansi** | Menelusuri keluhan, penanggung jawab, tindakan, dan penyelesaiannya. |

Untuk jasa digital, **bukti penyerahan file dan persetujuan hasil** dapat menggantikan kebutuhan surat jalan fisik. BAST digunakan sesuai kesepakatan pekerjaan.

**8. Administrasi keuangan dan penagihan**

| Dokumen / fitur | Fungsi |
|---|---|
| **Invoice uang muka / termin / pelunasan** | Menagih pembayaran sesuai tahapan yang disepakati. |
| **Nota penjualan** | Mencatat transaksi penjualan sederhana atau langsung, sesuai alur pembukuan perusahaan. |
| **Kwitansi / tanda terima pembayaran** | Menjadi bukti pembayaran telah diterima. |
| **Bukti kas masuk** | Mencatat penerimaan uang ke kas atau rekening. |
| **Bukti kas keluar** | Mencatat pembayaran biaya, pembelian, dan pengeluaran lain. |
| **Voucher pembayaran** | Mengajukan dan menyetujui pembayaran berdasarkan dokumen pendukung. |
| **Form reimbursement** | Mengajukan penggantian pengeluaran personel untuk kepentingan perusahaan. |
| **Form uang muka operasional** | Mencatat dana kerja yang diberikan sebelum kegiatan. |
| **Laporan pertanggungjawaban uang muka** | Mencocokkan dana yang diberikan dengan bukti penggunaan dan sisanya. |
| **Daftar piutang dan jatuh tempo** | Memantau tagihan pelanggan serta tindak lanjut penagihan. |
| **Daftar utang supplier** | Memantau kewajiban pembayaran kepada pemasok dan partner. |
| **Nota kredit / penyesuaian tagihan** | Mencatat koreksi atau pengurangan tagihan yang disetujui. |
| **Rekap biaya dan hasil proyek** | Membandingkan nilai pekerjaan dengan realisasi biaya proyek. |
| **Arsip dokumen pajak** | Menghubungkan dokumen perpajakan yang relevan dengan transaksi terkait. |

**Invoice adalah tagihan; kwitansi adalah bukti pembayaran diterima.** Satu transaksi dapat memiliki keduanya, tetapi pencatatannya harus terhubung agar tidak terjadi penghitungan ganda.

**9. Administrasi khusus advertising, video, dan event**

| Jenis pekerjaan | Dokumen tambahan |
|---|---|
| **Penempatan media / billboard / videotron** | Media order, titik penempatan, periode tayang, jadwal materi, bukti pemasangan atau penayangan, dan pengingat akhir sewa. |
| **Pengelolaan sosmed** | Kalender konten, persetujuan materi, jadwal publikasi, dan laporan hasil. |
| **Iklan digital** | Persetujuan anggaran, campaign brief, catatan belanja iklan, dan laporan performa. |
| **Video dan audio** | Treatment, storyboard, jadwal produksi, call sheet, persetujuan talent, serta daftar aset dan lisensinya. |
| **Event dan aktivasi** | Rundown, pembagian tugas, daftar perlengkapan, checklist pelaksanaan, dan laporan kegiatan. |
| **Website / teknologi** | Dokumen kebutuhan, milestone, hasil pengujian, persetujuan hasil, serta berita acara penyerahan akses. |

**10. Administrasi personel dan pengendalian internal**

| Dokumen / fitur | Fungsi |
|---|---|
| **Data personel dan pembagian peran** | Menentukan siapa menjalankan fungsi penjualan, operasional, keuangan, dan produksi. |
| **Absensi, izin, dan cuti** | Mengatur ketersediaan tim. |
| **Timesheet / pencatatan waktu** | Mencatat waktu pengerjaan jika dibutuhkan untuk kapasitas atau perhitungan proyek. |
| **Slip gaji / honor / lembur** | Mendokumentasikan pembayaran personel dan tenaga proyek. |
| **Laporan harian dan KPI** | Memantau pekerjaan, target, hambatan, serta tindak lanjut. |
| **Matriks persetujuan** | Menentukan kewenangan harga, diskon, pembelian, pembayaran, dan kontrak. |
| **Riwayat perubahan / audit trail** | Menyimpan siapa mengubah atau menyetujui data, kapan, dan apa perubahannya. |

Untuk **ERP tahap awal Utero**, saya menyarankan memulai dari 15 kebutuhan berikut:

| No. | Kebutuhan inti |
|---|---|
| 1 | Database pelanggan dan prospek |
| 2 | Form brief |
| 3 | Kalkulasi harga / RAB |
| 4 | Surat penawaran |
| 5 | Sales Order / Slip Order |
| 6 | Job Order / SPK internal |
| 7 | Persetujuan desain dan perubahan pekerjaan |
| 8 | Permintaan pembelian |
| 9 | PO supplier / SPK partner |
| 10 | Penerimaan barang dan pencatatan stok |
| 11 | QC dan laporan hasil pekerjaan |
| 12 | Surat jalan / bukti penyerahan |
| 13 | BAST |
| 14 | Invoice dan pemantauan piutang |
| 15 | Bukti pembayaran dan rekap biaya proyek |

Setiap dokumen perlu terhubung dengan **ID pelanggan, nomor proyek, nomor dokumen, tanggal, PIC, status, lampiran, dan persetujuan**. Item pekerjaan juga membawa spesifikasi, jumlah, satuan, harga, serta tenggat sesuai kebutuhan.

**Contoh satu pekerjaan neonbox:** brief → penawaran → persetujuan klien/PO → Slip Order → persetujuan desain → SPK Produksi → pembelian bahan → QC → Surat Jalan → pemasangan dan BAST → invoice → pembayaran.

Untuk admin baru, urutan belajarnya mengikuti alur tersebut: **kuasai pelanggan, brief, penawaran, dan Slip Order terlebih dahulu; kemudian pelajari produksi, pembelian, pengiriman, serta penagihan.**
